# 页面设计规范

## 整体风格

黑白极简，信息密度取向，专业工具感。白色背景 + 近黑色文字 + 浅灰边框，不装饰、不过度设计，让内容本身说话。

## 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#1a1a1a` | 按钮、选中态、链接 |
| 背景 | `#ffffff` | 页面底色 |
| 容器背景 | `#fafafa` | 表头、筛选栏、次要区域 |
| 边框 | `#f0f0f0` / `#e8e8e8` | 分割线、输入框边框 |
| 文字主色 | `#1a1a1a` | 标题、正文 |
| 文字次色 | `#8c8c8c` | 辅助说明、占位符 |
| 危险/强调 | `#cf1322` | 毒性标签、删除操作（仅必要时使用） |

## 字体

系统原生中文栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", sans-serif`。不引入外部字体，以屏显可读性优先，字号不做艺术化处理。

## 圆角与阴影

- 全局 `border-radius: 4px`，按钮、输入框、表格统一直角微圆
- **禁用 `box-shadow`**，不用卡片浮起、不用 Card 组件嵌套内容区块
- 信息区块之间用 `border-bottom: 1px solid #f0f0f0` 分割

## PC 端布局（≥768px）

- 内容区 `max-width: 1200px`，居中
- 顶部水平导航，白色背景 + 底部 1px 灰线，4-5 个导航项
- 列表页紧凑行展示，`Divider` 切割，不套 Card
- 详情页用 `Descriptions` 分区 + 水平分割线

## 移动端布局（<768px）

- 导航折叠为汉堡菜单或底部 TabBar
- 表格精简为核心字段，点击进详情
- 搜索框全宽，筛选折叠为下拉
- 详情页纵向堆叠
- 字号和间距不随视口缩放

## Ant Design 主题配置要点

通过 `ConfigProvider` 全局覆盖：`colorPrimary` 设为 `#1a1a1a`，`colorBgLayout` 设为 `#ffffff`，`borderRadius` 设为 `4`。Table headerBg 设为 `#fafafa`。覆盖默认蓝色为黑色系。

## 设计禁忌

- 不用 `Card`、不用阴影、不用渐变
- 不用蓝色做主色（Ant Design 默认蓝必须覆盖）
- 不用大面积色块装饰
- 不缩放字体大小
- 表格和列表不放在 Card 内
